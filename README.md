# The 3 AM Excuse

> Nope — it’s 3 AM, my keys are asleep in their pajamas, and this transaction reeks of a choice you’ll disown by breakfast.

Character count: 121

## Why it lands

The wallet talks like a tired device with its own bedtime, not a helpful assistant: its keys wear pajamas, so the refusal is personal and a little smug. The 3 AM hour does the work — the joke only makes sense at an hour when nobody should be signing anything, and the punchline (a choice disowned by breakfast) turns the late-night impulse itself into the reason to say no. No batteries, no firmware update, no cold-storage cliché: the excuse is the hour, and the wallet's grudge against it.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the line to `./out/entry.txt`.
